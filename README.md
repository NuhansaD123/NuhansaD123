## 💻 Git Commands I'm Practicing

```bash
# Create a repository
git init

# Clone a repository
git clone <repository-url>

# Check repository status
git status

# Stage changes
git add .

# Commit changes
git commit -m "Your commit message"

# Push changes
git push

# Pull changes
git pull

# View branches
git branch

# Create a new branch
git branch <branch-name>

# Switch branches
git switch <branch-name>

# Merge a branch
git merge <branch-name>

# View commit history
git log
```
